# Documento final do PIM IV (ABNT)

`PIM IV - Aprender Mais.docx`: trabalho completo no padrão do manual da UNIP (A4, margens 3/2 cm, Arial 12, espaçamento 1,5, numeração no canto superior direito a partir da Introdução).

| Parte | Conteúdo |
|---|---|
| Pré-textual | Capa, folha de rosto, resumo, abstract, lista de siglas, sumário |
| Textual | 1 Introdução · 2 a 10 Desenvolvimento (Etapas 1 a 9 do manual, 29 páginas) · 11 Conclusão |
| Pós-textual | Referências (ABNT NBR 6023) e Apêndice A (repositório e contas de demonstração) |

## Antes de entregar

1. Abra no **Word**. Ele pergunta se deseja *atualizar os campos*: responda **Sim**. É isso que preenche o **sumário** com as páginas.
   (Se não perguntar: clique com o botão direito no sumário → **Atualizar campo** → **Atualizar o índice inteiro**.)
2. Preencha o nome do(a) **orientador(a)** na folha de rosto.
3. Confira os papéis do time (seção 10) e os valores estimados (seção 3).
4. Salve também em PDF (**Arquivo → Salvar como → PDF**) para postar no sistema da UNIP.
